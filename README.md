## Overview

Adrenaline Thrills is a fitness club website designed to inspire and motivate individuals to work hard for a better life. The website provides information about the club, its challenges, and the community it fosters. This project showcases a responsive front-end implementation using HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: The website is fully responsive, ensuring a seamless experience on both desktop and mobile devices.
- **Navigation**: Easy access to various sections including Home, About Us, Challenges, and Blog.
- **Hero Section**: Engaging introduction to the fitness club with a call to action for users to get started.
- **About Us Section**: Information about the club and its coach, promoting a welcoming environment.
- **Video Section**: A dedicated area to explore fitness life through engaging video content.
- **Challenges Section**: A list of fitness challenges available for members to participate in.
- **Blog Section**: Latest news and articles related to fitness and health.
- **Newsletter Subscription**: Users can subscribe to receive updates and news.

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling the application and ensuring responsive design.
- **Google Fonts**: For custom typography.
- **Ionicons**: For scalable vector icons used throughout the site.

## Usage

- **Homepage**: Users can explore the main features and benefits of joining the fitness club.
- **Navigation**: Use the navigation bar to access different sections of the website.
- **Challenges**: View and participate in various fitness challenges.
- **Blog**: Read the latest articles and news related to fitness.
